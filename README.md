# EduQuest POC v2
Upload these files to the root of your GitHub Pages repo (keep `.nojekyll`).
1. Set `FEEDBACK_URL` and `SITE_URL` at the top of the script in `index.html`.
2. Optional feedback backend: paste `backend/Code.gs` into a Google Sheet's Apps Script, set `PASS`, deploy as Web app (Execute as: Me, Access: Anyone), copy the /exec URL into `FEEDBACK_URL`.
3. Admin view: `yoursite/#admin`.
